This build uses MPEG-TS demuxing and the h264_vita/aac_vita hardware
decoders. CPU H.264 is compiled for stream probing and host tests, but Vita
playback explicitly selects h264_vita. No Sony firmware files or external
console plugins are redistributed.

The release's corresponding codec source archive contains the exact FFmpeg
source archive, hardware patch, original license texts, configure/build recipe,
and generated configuration. tools/build-stream-codecs.sh reproduces the
dependency from pinned public sources. The client source and patch accompany
the VPK; keep those materials with any redistributed build.
